# WF-06 — structured Decision, fixed conditional routes

## Supported contract (approved A)

New decision tickets live only under `.workflow-decision-tickets`. They reuse definition/owner snapshots, source/artifact integrity, manual choice snapshots, typed manifests and explicit human review revisions without migrating old tickets or consuming the legacy queue.

An explicitly injected adapter must return exactly version1, label(pass/review/reject), finite numeric confidence0..1 and reason. Boolean/version confusion, extra route/command fields and unsupported values are rejected. Only fixed server label-eq or confidence-eq/gte/lte predicates are evaluated; exactly one a/b match is required. Both/no matches fail with no fallback or hidden priority. review/reject labels do not create human gates or terminate branches.

The initial judgment requires an explicit plan/cost confirmation. Input SHA/metadata, descriptor ID/revision/schema, structured result, predicates/matches and selected port persist in real files. A successful judgment waits without holding a process; already-running independent work settles and is preserved. The unjudged route is unresolved, not skipped or free. Only a fresh plan bound to the result, remaining route and current nonsecret serving permits a separate continuation. It does not offer human route reselection. Successful judgments/terminal results are not repeated after review gates. Exact repeated request IDs are deduped; mismatched requests, changed source/conditions and fixed report/route SHA tampering are rejected. No generic retry/crash recovery is introduced.

Error classes distinguish adapter_error / format_error / condition_error / input_integrity_error. Invalid untrusted raw responses and provider diagnostics are not copied into tickets; safe codes are persisted. Dependent steps are blocked on error, never normal skipped. Only normal successful nonselection skips branches. Required selected joins keep waiting for explicit gates and remain typed reference manifests, not merged media.

Media inputs currently provide verified **metadata only** to the decision adapter, not raw audiovisual model inference. Bounded JSON/UTF-8 types use readonly content (1MiB max). Reason text is never executed. Registration, per-node model binding and live inference are not implied by an injected descriptor. Production factories remain absent.
