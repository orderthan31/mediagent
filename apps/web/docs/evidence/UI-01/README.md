## Binding and admission
ModelRegistry/WorkTicketStore/RegisteredMediaExecutor/RegisteredDecisionProvider are real source implementations, not decorative dropdowns or injected descriptor substitutes. The native/client configuration receives the exact resolved provider/model for each node; the descriptor is protocol identity derived from that entity. Server compatibility checks use supported adapter contracts and reject unsupported combinations/model-free-node refs; they do NOT establish that arbitrary model names exist or work at a provider. Every registration/availability display says inference/connection unverified.

On start/continue an old plan cannot bypass changed usage state. Per-node admission rechecks owner, immutable revision/content, compatibility and current availability before a pending call. A stopped model call is blocked, descendants blocked, independent successful results preserved. Already successful judgment is not re-invoked, even after disable and review. No blanket invalidation of completed/independent outputs. Reactivation does not auto-run failed/blocked work. No generic retry/cancel/crash recovery added. Legacy registry-free WF03–06/manual choices/queue/shared role settings remain separate and unconverted; new bound definitions are explicitly rejected by legacy compilers rather than silently ignoring refs.
