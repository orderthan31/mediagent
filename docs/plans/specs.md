# mideagent 제품 요구사항

## 목적

기존 ‘장면’의 영상·음성·자막 작업을 셀프호스팅 제품 mideagent로 제공한다. 한 번에 고정된 처리를 강요하지 않고, 독립된 업무 에이전트를 연결한 저장 워크플로우로 같은 작업을 수행한다.

## 현재 상태

개발 브랜치는 `renewal`이다. 요구사항 확정, 코드 존재, 모의 검사, 실제 공급자 호출, 격리 제품 실행과 운영 배포는 서로 다른 상태다. 사용자 승인에 따라 혜지가 VPS 개발과 기존 SSH를 통한 Windows 소스 갱신·실행·GPU 검증을 맡는다. 구현 현황은 [태스크](tasks.md), 기술 계약은 [실행 계약](../references/high/runtime.md)에서 관리한다.

## 주요 내용

### 입력과 결과

- 영상·음성·자막 중 업무에 필요한 입력을 선택한다. 원본과 기존 결과는 보존하고 새 작업·수정본을 별도로 만든다.
- 음성 추출, 전처리·무음/VAD와 원본 시각 복원, 전사, 번역, 자막 파일 생성, 자막 영상 제작, 자막 없는 영상 변환을 필요한 조합으로 제공한다.
- 전사만, 번역만, 인코딩만 또는 전체 처리를 선택할 수 있어야 한다. 이미 만든 오디오·전사문·자막을 재사용할 때 앞 단계를 강제로 다시 실행하지 않는다.
- 원문과 번역 자막, SRT/SMI, 번인/소프트 자막과 지원 인코딩 설정을 선택한다. 한국어 번역·번인 프리셋은 예시이며 모든 작업의 고정 조건이 아니다.
- 직접 선택한 UTF-8 SRT와 지원되는 단일 언어 SMI의 문구·시각을 편집하고 별도 수정본으로 저장·재열기·다운로드한다. 미지원 파일을 추측 변환하거나 원본을 덮어쓰지 않는다.
- 작업별 중간·최종 결과를 조회·다운로드한다. 영상 결과는 실제 파일·자막·재생까지 확인해야 완료다.

### 에이전트와 워크플로우

- 각 업무 에이전트가 자기 입력·설정·도구·진행 상태·결과를 소유한다. 분석·분할·모델 호출·인코딩 등의 내부 도구를 업무 에이전트와 혼동하지 않는다.
- 워크플로우는 에이전트의 연결과 필요한 순서·분기·병렬·합류·사람 검수·판단을 표현한다. 사용자는 편집한 정의를 저장하고 다시 열어 실제 실행에 사용한다.
- 작업 하나는 선택한 원본과 저장 워크플로우의 실행이며 티켓번호로 식별한다. 내부 실행기 종류별로 기본 작업 화면을 분리하지 않는다.
- 에이전트 종류의 활성화·비활성화와 실행 인스턴스 수는 관리자 운영 기능이다. 사용하지 않는 선택 기능 때문에 다른 업무가 막히지 않아야 한다.

### 모델과 설정

- 서빙에서 공급자 연결과 모델을 등록하고, 모델을 사용하는 워크플로우 노드에서 호환 모델·언어·요청 옵션을 선택한다. 로컬·온프레미스 OpenAI-compatible 주소도 같은 연결 개념으로 취급한다.
- 업무 코드에 특정 LLM 이름을 고정하지 않는다. 작업에 저장된 선택과 후보 순서를 실제 요청까지 유지하며 지원하지 않는 입력·옵션은 명시적으로 거절한다.
- 새 전사·번역 워크플로우의 모델 호출량은 실제 준비된 입력과 선택 후보를 기준으로 유한하게 산정한다. 사용자가 명시한 숫자 한도와 기존 실행 스냅샷은 유지하며, 자동 산정을 무제한 호출·불명 결과 재시도 권한으로 해석하지 않는다.
- 같은 공급자 연결은 호환되는 여러 업무가 재사용한다. 키를 전사용·번역용으로 불필요하게 분리하거나 workflow·작업·로그에 복사하지 않는다.

### 원자성과 결과 보존

- 작업 생성·실행 승인·단계 결과 반영은 입력·정의·설정과 결속되어야 한다. 동일 요청의 재전송이 중복 작업·중복 다음 단계 실행을 만들면 안 된다.
- 검증된 결과와 상태를 함께 확정하고, 취소되거나 오래된 실행의 늦은 결과를 현재 정상 결과로 반영하지 않는다.
- 한 가지의 실패·검수 대기가 이미 완료된 독립 가지의 결과를 지우면 안 된다. 합류는 필요한 선택 결과를 기준으로 판단한다.
- 저장·검수 승인과 실행을 분리한다. 유료 호출은 유효한 확인과 명시 실행을 요구하며 응답 불명 호출을 자동 재시도하거나 다른 모델로 우회하지 않는다.
- 외부 공급자 과금까지 되돌리는 전역 트랜잭션이나 외부 요청의 정확히 한 번 실행을 보장한다고 표현하지 않는다.

### 사용과 운영

- 인증된 사용자는 공용 원본·작업·결과를 사용한다. 계정은 행위자 기록이며 관리자 설정·공급자 비밀은 별도로 보호한다.
- 시작 전 대기 작업의 일시정지·재개·순서를 제어하고 이미 진행 중인 처리와 구분한다. 기존·불명 작업을 자동 재등록하지 않는다.
- 처리 상태·오류와 실제 stdout/stderr를 작업 상세에서 확인한다. 기록하지 않은 과거 로그를 만들지 않는다.
- 전체 청크와 완료·실패·처리 중·미확정 수를 실제 계획·기록에 따라 구분한다. 전체를 모르면 미확인으로 표시하고 호출 상한이나 관찰된 요청 수로 추정하지 않는다. 실행 기록과 원본 콘솔은 별개이며, 도구 요청의 반환을 공급자 성공이나 전체 작업 완료로 표시하지 않는다.
- 모델 호출을 다루는 비공개 로그에는 실제 실행 경계의 진단만 공개하고 요청·응답·인증 본문과 자유형 출력은 숨긴다. 기존 비공개 원문 기록은 보존하되 안전성이 확인되지 않은 과거 본문을 화면에 다시 노출하지 않는다.
- 저장 용량은 화면에서 GB 소수점 둘째 자리로 표시하되 DB/API의 원시 바이트는 유지한다.
- PostgreSQL 메타데이터, 미디어 저장소, 메시지 전달과 실행 상태를 구분한다. 최종 웹·백엔드의 VPS 배치와 GPU·모델 처리의 5070 Ti 배치는 유지할 방향이며 즉시 이전 지시가 아니다.

### 이번 범위 밖

FaceFusion 개발·실행은 제외한다. 기존 관련 코드·자료가 있다는 이유로 삭제·롤백하지 않으며 핵심 영상·음성·자막 완료의 선행 조건으로 두지 않는다. 기존 원본·DB·키·백업·WIP·불명 호출과 감사 기록은 보존한다.

## 미확정 사항

최종 배포 전환의 구체 경로·운영 자원 한도와 미승인 변경은 [미확정 기획](ideation.md)에서 구분한다. 분석에서 제안한 구현 순서를 사용자 확정 요구로 승격하지 않는다.
