# 현재 작업과 미완료 기능

## 목적

확정된 제품 요구의 완료 여부만 관리한다. 과거 실행 로그·검사 횟수·마일스톤 보고를 누적하는 작업 지시서로 사용하지 않는다.

## 현재 상태

사용자 요청에 따라 최신 `renewal`을 직접 분석·정리하고 있다. 자동 후속 개발과 혜윤에게의 개발 재인계는 중단 상태다. 분석 근거·정리 변경·다음 작업 방법을 사용자에게 먼저 보고한다. 이 문서의 체크리스트는 재개 지시가 아니다.

## 주요 내용

### 이번 분석·정리

- [x] 혜윤의 최신 제품 소스와 원격 `renewal`의 동일 HEAD·clean 상태를 확인한다.
- [x] 전체 추적 파일을 분류하고, 기존 `master`·재개 전 `df3f495`와 변경 내용을 대조한다.
- [x] 프론트 기본 검사·빌드와 백엔드 전체 수집·네트워크 제한 검사를 실행하고 제품 결함과 환경·테스트 문제를 구분한다.
- [x] 제품 코드를 실행하지 않고 소스 문자열만 검색하던 테스트 9개 파일을 제거한다. 실제 동작·원자성·취소·보존 테스트는 실패하더라도 삭제하지 않는다.
- [x] 잘못된 역할 메시지가 소비자를 중단시키는 입력 검증 순서를 보정한다. 기존 실패 재현 테스트를 유지한다.
- [x] 오디오/이미지 테스트에서 개인 Windows FFmpeg 절대 경로를 제거한다. 실제 미디어 검증은 유지한다.
- [x] 기존 기획 문서의 중복 보고·오래된 실행 제한을 제거하고 요구사항·구조·디자인·현재 작업을 분리한다.

### 기존 코드가 있으나 전체 수용되지 않은 기능

- [ ] 새 업무 에이전트 workflow와 기존 분기·병렬·합류·사람 검수·판단의 실제 결합.
- [ ] 전사만·자막 번역만·자막 파일 생성·자막 영상·영상 변환·전체 처리의 실제 입력부터 결과까지 연결. 업무와 관계없는 영상 입력이나 앞 단계 재실행을 강제하지 않는다.
- [ ] 승인된 짧은 새 영상으로 실제 선택 모델 전사 → 번역 → 자막 번인 → MP4 다운로드·재생. 기존 불명 작업을 재사용하지 않는다.
- [ ] 내부 TLS 연결과 실제 배포 버전·저장된 모델/옵션의 일치. 신뢰 검증을 끄거나 새 공개 연결을 추가하지 않는다.
- [ ] 같은 요청 재전송·중간 실패·취소·늦은 결과에서 중복 처리와 잘못된 완료가 없는지, 독립 결과가 보존되는지 실제 실행 경로로 확인.
- [ ] 작업이 들어 있는 대기열의 일시정지·순서·재개 실행. 빈 대기열 조작과 구분한다.
- [ ] 필요한 입력·설정·상태·오류·실제 로그·결과를 PC와 휴대폰에서 일관된 동선으로 제공.

FaceFusion은 위 완료 목록에서 제외한다. 실제 모델·영상 결과와 무관한 추가 입력 준비 화면이나 반복 검사 보고를 별도 성과로 늘리지 않는다.

## 미확정 사항

위 미완료 목록의 구현 순서는 분석 보고에서 제안하며, 사용자에게 보고하기 전에 혜윤에게 실행 지시하지 않는다. 현재 통과한 일부 검사로 전체 suite·실제 모델·제품이 정상이라고 표시하지 않는다.
