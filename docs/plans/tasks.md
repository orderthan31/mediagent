# 현재 구현 태스크

## 목적

현재 확정된 작업 묶음을 체크리스트로 관리한다. 미검증 작업은 완료로 표시하지 않는다.

## 현재 상태

문서 규칙·현행 기획의 저장소 전환을 적용했다. 기존 인프라 WIP와 실패한 재생 검증을 보존하며 GPU 연결만 남은 상태로 보고하지 않는다.

## 주요 내용

### 문서 체계

- [x] 참조 프로젝트 Common을 보존하고 미디에이전트 Special·템플릿·규칙 인덱스를 적용한다.
- [x] 기존 구형 문서를 현행 안내와 분리하고 이동·링크·보존 및 Common 일치를 확인한다.

### 인프라·독립 에이전트

- [ ] 현재 PG/콘텐츠/CPU/API/프론트 WIP를 최종 검토·회귀하고 일반 소스 공유를 완료한다.
- [ ] `workers`/`media_worker` 명칭을 `agents` 구조에 맞춰 변경하고 패키징·import·CLI·Docker·스크립트·테스트 참조를 함께 정리한다.
- [ ] 독립 에이전트의 개별 진입점, 외부 명령 수신·결과 반환·중복/취소/불명 결과 처리와 애플리케이션 제어를 연결한다. 기존 운영 큐는 소비하지 않는다.
- [ ] S3-compatible 미디어 저장소 adapter를 구현하고 로컬 공유경로 없이 원본/중간/산출물의 계정·무결성·불변 참조 전달을 검증한다.
- [ ] API·frontend·각 에이전트의 저장소/전송 연결을 실제 격리 환경으로 검증한다. 단일 호스트 subprocess 증거와 분산 증거를 구분한다.
- [ ] 합성 CPU 처리 결과의 브라우저 재생 실패를 원인 분류·수정 또는 환경 한계로 확정하고 다운로드 무결성 검증과 분리한다.
- [ ] 구형 단일 파이프라인·POC·불필요한 파일은 참조·이관 여부와 보호 대상을 확인한 뒤 제거한다. 사용자 원본·자막·DB·비밀정보·백업은 삭제하지 않는다.

### 최종 사용·실행 경계

- [ ] 작업 생성·실행 승인·공통 검수·취소/복구·최종 결과까지 현재 실제 화면을 연결해 검증한다.
- [ ] GPU/실모델 고유 잔여와 인프라 잔여를 구분한다. 별도 승인 전 실제 provider/GPU/유료/운영 큐·데이터를 실행하지 않는다.
