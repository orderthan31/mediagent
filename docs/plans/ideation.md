# 미확정 기획

## 목적

아직 확정되지 않은 선택과 브레인스토밍만 관리한다.

## 현재 상태

확정된 인프라/명칭/문서 정리는 tasks에서 관리한다. 아래 후보는 배포 완료나 제품 선정으로 보지 않는다.

## 주요 내용

- S3-compatible 오브젝트 스토리지의 구체 서버 제품·버전·운영 위치. MinIO 도입 언급을 원래 기획과 대조하되 이름만으로 설치·라이선스·지원 범위가 검증됐다고 하지 않는다.
- RabbitMQ의 운영 버전·HA/보관 정책·계정 권한·실제 queue namespace. 개발 adapter는 역할별 명령/결과/격리 큐를 구현하지만 운영 브로커나 기존 큐를 자동 연결하지 않는다.
- 최종 VPS/5070 Ti 역할 분할과 비공개 미디어 전달 경로·인증·보관 정책의 운영 설정. 기능 완성 후 별도 실행 범위를 확정한다.
- 정식 릴리스 산출물의 게시 위치와 구성요소 버전 노출 방식.

### 에이전트 운영 관리의 미확정 정책

활성화·비활성화·목표 개수·작업 분산과 관리자 전용 권한은 확정 요구다. 작업 승인에 따라 로컬 CPU에는 신규 배정 차단→예약 작업 마무리→종료, 목표/실제 상태 분리, 인스턴스당 1개·종류별 최대 8개·전체 최대 16개의 보수적인 구현 한도를 적용했다. 운영 환경에 대한 실행 승인이나 GPU 자원 정책 확정은 아니다.

- drain 제한시간·강제중지 권한과 자원 부족 시 운영 대기열 정책. 현 명시 CPU 호출은 비활성화된 노드의 신규 배정을 거부하며 자동 큐 재실행은 하지 않는다.
- 실제 CPU/GPU 자원 한도·quota와 다중 호스트 부하 분산 정책. 로컬 개수 한도를 GPU 용량 증가나 컨테이너 자원 격리로 취급하지 않는다.
- controller 장애 후 남은 인스턴스 상태 확인·소유권 인계. 현재는 타 controller PID를 채택/종료하거나 상태를 자동 성공 처리하지 않는다.
- 운영 제어 방식: Compose 기반 제어와 외부 실행 관리자의 경계, 허용 호스트와 대상 이미지/명령의 범위를 결정한다. 일반 API에 무제한 컨테이너·셸 제어 권한을 제공하는 방식으로 결정하지 않는다.

## 미확정 사항

위 항목은 검토·결정이 필요하다. 미확정안을 구현 완료나 운영 실행 승인으로 바꾸지 않는다.
