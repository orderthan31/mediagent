## Special

### 미디에이전트 적용 범위

- 루트 `AGENTS.md`와 하위 `AGENTS.md`는 이 규칙 인덱스를 참조한다. 규칙 본문을 각각 복제하지 않는다.
- `Common`은 참조 프로젝트의 공통 규칙을 유지하며, 미디에이전트의 기술·보호·운영 조건은 각 문서의 `Special`에서 관리한다.
- 현재 제품 기획은 [specs](../plans/specs.md), 구조는 [architect](../plans/architect.md), 디자인은 [design](../plans/design.md), 확정 작업은 [tasks](../plans/tasks.md), 미확정안은 [ideation](../plans/ideation.md)을 따른다.
- 과거 기록은 [archive 안내](../references/archive/README.md)를 통해 필요할 때만 조회한다.
