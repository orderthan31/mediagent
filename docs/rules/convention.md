### 프론트엔드 (`apps/web`)

- 컴포넌트·훅·도우미·콜백은 `const` 화살표 함수를 우선한다. prototype/`this` 의미가 필요한 생성자·클래스 메서드는 유지한다.
- React 컴포넌트·커스텀 훅은 state/ref/파생값 → 핸들러 → effect 전용 훅 → render guard/JSX 순서로 선언한다. 훅 순서를 유지하며 guard 전에는 안전하지 않은 값을 계산하지 않는다.
- `if`/`else`는 한 줄이어도 중괄호를 사용한다. Prettier로 읽기 쉬운 여러 줄 코드와 JSX를 유지한다.
- 커밋 전 `npm run lint`, `npm run format:check`, `npm test`, `npm run build`를 실행한다. 기존 전체 lint/format 부채와 변경 파일 결함을 분리해서 기록하며 오류를 숨기거나 검사를 삭제하지 않는다.
- 한결디자인의 실제 설치 소스·제품 토큰을 사용한다. 공용 디자인 시스템 정본을 제품 수정에 섞어 변경하지 않는다.

### API·저장소·에이전트

- Python API와 에이전트는 명시 의존성을 받는다. import 시 DB migration·운영 설정 탐색·백그라운드 실행·큐 소비·외부 호출을 시작하지 않는다.
- 독립 에이전트는 자신의 입력/설정/출력 계약만 해석한다. 전체 workflow 순서·후속 에이전트·웹 세션·사람 검수·실행 동의는 애플리케이션이 소유한다.
- 메타데이터는 PostgreSQL에, 미디어는 검증된 artifact 참조로 분리한다. 원격 오브젝트 스토리지 도입 전 로컬 공유 경로를 분산 동작으로 부르지 않는다.
- 명칭과 경로 변경은 import·패키징·진입점·스크립트·Docker·테스트 참조를 함께 수정하고 확인한다. 변수명 일괄 치환으로 외부 프로토콜/DB 식별자/과거 증적을 임의 변경하지 않는다.
- credentials·DSN·세션·서명 URL은 workflow/명령/일반 로그에 넣지 않는다. 중복·결과 불명 요청을 자동 재실행하지 않으며 실패 근거를 보존한다.
